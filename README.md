Story Goal= By September 24, we can answer one real question about currency exchange rates by running a SQL query across data our own code has been collecting since September 10.

Story Line = As an international investor, I want to access current currency exchange rates, along with the corresponding currency symbols and countries, so that I can stay informed about global currency values and make better-informed decisions when monitoring international financial markets.

Team 6 choose to use the Frankfuter API for currency conversion rates.

The purpose of this project is to collect and organize currency information from two related API endpoints so that users can easily review and compare currency data.

The first endpoint retrieves currency exchange rate information, including the exchange rate and the date associated with that rate. This allows the system to track how currencies are valued and when the rate was recorded.

The second endpoint retrieves information about currencies, including the country associated with the currency and its currency symbol. This provides additional context that helps identify and understand each currency.

The data from both endpoints is then brought together in the Build.db database. By combining the exchange rate, date, country, and currency symbol, the database creates a centralized dataset that can be used for comparison, analysis, and review.
